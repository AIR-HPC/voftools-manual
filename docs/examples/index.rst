4 Verification and validation
=============================

.. _sec:test-program:

The ``VOFTools`` package includes a comprehensive suite of test programs designed to assess the accuracy, robustness, and performance of the implemented geometric operations. These tests are divided into two primary categories:

#. **PLIC operations:** focusing on piecewise linear interface reconstruction (Section \ :ref:`4.1 <sec:plic-operations>`\ ), and

#. **PPIC operations:** focusing on piecewise paraboloidal interface reconstruction (Section \ :ref:`4.2 <sec:ppic-operations>`\ ).
