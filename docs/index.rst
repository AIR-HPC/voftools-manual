VOFTools 6
==========

Analytical and geometrical tools for VOF methods in arbitrary grids
----------------------------------------------------------------------

**User manual · Joaquín López · 2026**

VOFTools provides Fortran, C and Python interfaces for geometric operations
on polygonal and polyhedral cells, including PLIC and PPIC reconstruction.
